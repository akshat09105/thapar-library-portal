1. Computer Vision Pipeline (IoU Spatial Alignment)

Inspired by and expanding upon jasminekaur7/smart-library-seating-system, our system utilizes dual-object bounding box correlation. When a camera captures an angled view of the library study hall:

  • Chairs & Desks: Identified across multi-scale feature pyramid layers ($P_3, P_4, P_5$).
  • Patrons & Students: Detected using upper-body torso and head bounding boxes.
  • Perspective IoU Formula: Evaluates the spatial intersection over union:
    IoU = Area(Chair ∩ Person) / Area(Chair ∪ Person)
    If $IoU \ge 0.30$, the seat is marked OCCUPIED (Red). If $IoU < 0.30$, it is verified as VACANT (Green).
